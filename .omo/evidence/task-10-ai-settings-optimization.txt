1. 增强共享 hook src/features/library/hooks/useAutoSave.ts（向后兼容）：
   - 返回值从 { isSaving } 扩展为 { isSaving, flush, pause, resume }
   - flush(): Promise<boolean> —— 手动持久化最新值；已保存→true，暂停/禁用/并发中→false，
     保存成功→true，保存失败/onSave 返回字符串→false（且触发 onError）
   - 新增 pausedRef；pause() 清 debounce timer 并置 pausedRef=true；resume() 置 false 并
     若仍有未保存变更则重新 schedule flush
   - 自动调度 useEffect + finally 里的重新调度均增加 !pausedRef.current 门槛
   - 原 flush 内部 void 调用（scheduleFlush 的定时回调）不受影响（仍 fire-and-forget）
2. 新增 src/features/library/hooks/useAiSettingsAutoSave.ts：
   - 包装 useAutoSave，暴露 flush/pause/resume
   - 用 suspend 计数（pauseCountRef）合并多暂停源：每个 pause() 计数+1，仅当首次 0→1 时
     调 autoSave.pause()；每个 resume() 计数-1，仅当归 0 时调 autoSave.resume()
   - 支持嵌套暂停（如"测试全部 API"进行中又触发"导入"），必须全部 release 才恢复
3. AiSettingsDialog.tsx 接线：
   - import 从 useAutoSave 改为 useAiSettingsAutoSave
   - enabled 从 `canSaveSettings && !isTestingAllProfiles` 简化为 `canSaveSettings`
     （测试暂停改由 autoSave.pause()/resume() 统一处理）
   - handleTestAllProfiles() 在 setIsTestingAllProfiles(true) 后调 autoSave.pause()，
     finally 里 setIsTestingAllProfiles(false) 后调 autoSave.resume()
