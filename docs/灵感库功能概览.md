# 素言（SuYan）灵感库功能概览

> 用途：给其它智能体 / 协作者快速了解「灵感库」模块现状，方便在其基础上继续添加功能。
> 最后核对时间：2026-08-26（基于当前 master 的 `src/features/prompts` 与 `electron/main/ai/promptAnalysisService.ts`）。

---

## 1. 模块定位

- **是什么**：素言（AI 绘图提示词管理工具）里与「图库（library）」并列的两大核心模块之一，用于管理**灵感 / 提示词条目**（含账号、API 配置、工作流等非图片内容）。
- **代码位置**：
  - 渲染层：`src/features/prompts/`（类型、store、组件、utils）
  - 主进程持久化与 AI：`electron/main/library/promptStore.ts`、`electron/main/ai/promptAnalysisService.ts`
  - 进程间契约：`electron/shared/ipcChannels.ts`（通道名）、`electron/shared/promptImportParser.ts`
- **技术栈**：React + TypeScript + Zustand（`usePromptStore`）+ `@dnd-kit`（拖拽）+ Tailwind 胶囊色系（`CAPSULE_TONES`）。
- **架构边界**：渲染进程**不直接**访问 Node/文件系统；所有读写经 `preload + contextBridge + ipcRenderer/ipcMain`（`window.suyanApi.*` 白名单）。

## 2. 数据模型（`src/features/prompts/types.ts`）

### PromptEntry（单条灵感）
| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一 ID |
| `type` | PromptType | 见下 |
| `title` / `description` | string | 标题 / 说明（可来自 system / ai / user，见 `metadataSource`） |
| `content` | string | 纯文本正文（供搜索与 AI 分析） |
| `contentHtml` | string? | 受限 HTML 正文（富文本展示用） |
| `categoryId` | string? | 所属分类 |
| `tagIds` | string[] | 标签 |
| `favorite` | boolean | 收藏 |
| `variables` | PromptVariable[] | `{ name, defaultValue?, description? }` 占位变量 |
| `usageCount` / `lastUsedAt` | number / string? | 使用统计 |
| `orderKey` | string | 手动排序键 |
| `colorId` | PromptColorId? | 卡片胶囊色（15 色系） |
| `source` / `sourceUrl` | 枚举 / string? | manual / clipboard / import / duplicate |
| `analysisStatus` | "analyzing"\|"ready"\|"failed"? | AI 分析状态 |
| `metadataSource` | PromptMetadataSource? | 各字段来源 system/ai/user，供 AI 回填与用户覆盖 |
| `masked` | boolean? | 脱敏显示偏好 |
| `cardWidth` / `cardHeight` | number? | 卡片自定义尺寸（220–640 / 260–720） |
| `account` | PromptAccount? | 账号结构化数据（密码仅密文） |

### PromptType
`"text" | "image" | "video" | "workflow" | "api-config" | "email-config" | "account"`

### 其它类型
- `PromptAccount`：账号条目，密码 `passwordEncrypted`（safeStorage 密文 base64），**明文永不落盘**；读取经 `prompt:account-read` 解密到内存（`PromptAccountView`）。
- `PromptCategory`：`{ id, name, icon?, color?, description?, orderKey, isDefault, createdAt, updatedAt }`。
- `PromptLibraryFile`：`{ schemaVersion: 2, updatedAt, entries[], categories[] }`。
- `PromptViewSettings`：`sidebarMode / sidebarWidth / viewMode(grid|list) / sortMode / cardDensity`。

## 3. 用户功能（主界面 `PromptLibrary.tsx`）

- **增删改**：新建、粘贴导入（`⌘⇧V`）、批量导入 / 导出（JSON 交换文件）、编辑、删除、复制（带变量替换）、收藏、复用（duplicate）。
- **工作区筛选**：全部 / 收藏 / 最近使用 / 最常使用。
- **分类 + 标签筛选**：分类下拉（含拖拽到分类移动）、标签下拉。
- **搜索**：标题、内容、分类名、标签、账号名 / 站点（`promptSearch.searchPrompts` 子串匹配，大小写不敏感）。
- **排序**：手动 / 最近修改 / 最近创建 / 最近使用 / 最常使用 / 名称 A-Z。
- **视图**：网格（瀑布流 masonry，卡片可拖拽改尺寸）/ 列表双模式。
- **拖拽**：`@dnd-kit` 实现手动排序；拖卡片到分类入口即移动分类。
- **批量**：多选（点击选中 / `⌘A` 全选 / 反选）/ 批量删除。
- **分类管理**（`CategoryManagerDialog`）：增删改、拖拽排序、合并（`mergeCategories`）。
- **标签管理**（`TagManagerDialog`）：重命名、删除（同步清理条目 tagIds）。
- **快捷键**：`⌘K` 搜索、`⌘N` 新建、`⌘A` 全选、`⌘⇧V` 粘贴、`Esc` 关闭、`Delete` 删除。

## 4. 核心子能力（`src/features/prompts/utils`）

| 文件 | 职责 |
|---|---|
| `promptClassification.ts` | **本地规则分类**：正则识别 账号 / 邮箱 / API Key，远程 AI 失败时的兜底归类（不依赖网络） |
| `promptVariables.ts` | 变量抽取 `extractPromptVariables` 与渲染 `renderPromptVariables`（`{name}` 占位） |
| `promptRedaction.ts` | 敏感信息检测 `findSensitiveMatches` 与脱敏 `redactPrompt`（可切换 `masked` 显示） |
| `promptClipboardParser.ts` | 剪贴板文本解析、`derivePromptTitle` 派生标题 |
| `promptAccount.ts` | 账号类型 / 内容识别（`detectAccountType` / `parseAccountContent`） |
| `promptSearch.ts` | 搜索、标签计数、标签筛选、排序 |
| `promptOrder.ts` | 排序键 `createOrderKey` / `compareOrderKey` |
| `promptSelection.ts` | 选区反选等 |
| `promptColors.ts` | 卡片配色 `getPromptColor` / `PROMPT_CARD_COLORS` |
| `promptMasonry.ts` | 瀑布流分列 `distributePromptMasonryItems` |
| `promptCardSizing.ts` | 卡片尺寸钳制 |
| `promptRichText.ts` | 富文本提取 / 清洗 / 图片名提取 |

## 5. AI 集成（主进程 `promptAnalysisService.ts` + `ai:` IPC）

- **Provider 配置**：远程 AI（OpenAI 风格兼容），支持多 profile / 多模型 / 按动作自定义指令（`aiSettingsModel`）。调用发生在主进程，渲染层经 `window.suyanApi.*` 调用。
- **能力（IPC 通道）**：
  - `ai:analyze-prompt`：`target` ∈ `prompt-category | prompt-tags | prompt-options | image-category | image-tags | image-safety`
  - `ai:prepare-prompt-entry`：**新建归档核心管线**——一次性整理 标题 + 分类 + 标签 + 描述；远程 AI 任一项失败时**降级为本地结果**（`classifyPromptContent` / `derivePromptTitle`），并附 `warnings`。
  - `ai:optimize-prompt`：提示词优化
  - `ai:summarize-prompt-title`：标题生成
  - `ai:translate-prompt`：中英互译
  - `ai:reverse-image-prompt`：图生提示词
  - `ai:image-generation`：文生图，完成 / 失败经 **TapRelay**（`http://localhost:1122/send`，即你部署的跨网络通知推送）推送手机。
- **分类映射**：远程 AI 标签 → `src/features/library/utils/categoryAiBinding.ts` 映射到本地「摄影流派分类树（taxonomy）」；高置信度自动套用、中置信度确认、低置信度进 inbox。
- **type 推断**（`createLocalPromptEntryData`）：依据关键词把粘贴内容判为 `video / workflow / api-config / email-config / text / image`。

## 6. 存储与 IPC

- **渲染层 store**：`usePromptStore`（Zustand）。
- **主进程持久化**：`electron/main/library/promptStore.ts`，落盘文件 **`data/library/prompts.json`**（`getPromptsPath()`），标记 `kind: "suyan-inspiration-library"`，`schemaVersion: 2`，支持 v1→v2 迁移；与图库共用 `data/library/` 目录（便携 / 安装版一致）。
- **账号密码**：`safeStorage` 加密，明文只在内存；读取走 `prompt:account-read`。
- **外部 IPC 通道（`IpcChannelName.Prompt*` / `Ai*`）**：
  - 条目：`prompt:list / create / update / delete / copy / favorite / duplicate / create-many / clipboard-read / content-image-choose / content-image-save / account-read`
  - 排序 / 移动：`prompt:reorder / move-to-category`
  - 分类：`prompt:category-list / create / update / delete / reorder / merge`
  - 交换：`prompt:export / import`
  - AI：`ai:analyze-prompt / prepare-prompt-entry / optimize-prompt / summarize-prompt-title / translate-prompt / reverse-image-prompt`

---

## 7. 与图库（library）的关系

- 灵感库独立管理提示词条目；图库图片可关联「提示词组」（PromptGroup），从图库反查 / 粘贴导入解析 ComfyUI workflow 生成提示词（`image-reverse`、富文本解析）。
- 共享 `viewSettings`（侧栏、视图、排序偏好，存于 `viewSettingsStore`）。

## 8. 给「继续添加功能」的开发者的扩展点提示

1. **新增 `PromptType`**：需同步 `types.ts`、`promptClassification`/`createLocalPromptEntryData` 的本地正则与 AI type 推断、`PromptCard` 渲染分支。
2. **新增元数据字段**：在 `metadataSource` 标注 `system/ai/user` 来源，便于 AI 回填与用户覆盖；渲染层 `normalizePromptFileForRender` 需补规范化分支。
3. **AI 整理管线**：`preparePromptEntryWithAi` 是核心扩展点——改分类体系 / 标签策略 / 降级逻辑都在此；务必保持「AI 失败降级本地」的兜底契约。
4. **敏感字段**：账号密码加密规则不可破坏；新增含敏感内容的 type 必须走 `promptRedaction` 脱敏。
5. **落盘契约**：`prompts.json` 版本升级需保持 `schemaVersion` 校验与迁移（`PROMPT_STORE_VERSION_UNSUPPORTED`）；交换文件 `kind` 必须是 `suyan-inspiration-library`。
6. **进程边界**：任何新能力若要碰文件 / 网络 / 系统，必须在主进程加 IPC handler 并经 `preload` 暴露，渲染层不得直连。
