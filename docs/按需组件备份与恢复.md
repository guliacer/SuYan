## 本地备份

- 源包：`release-components/6.0-suyan.1/`、`release-components/nsfw-1.0.0-signed/`。
- 独立备份：`recovery-backups/components-2026-09-08T06-37-26-511Z/`。
- 每套包含 ZIP、`manifest.json`、`manifest.json.sig`。已校验 Ed25519 签名、ZIP 哈希及清单中全部文件哈希。
- 此备份仍在同一磁盘，不能代替异机备份。

复核并新增带时间戳备份（先完成 Electron 构建）：

```powershell
node scripts/components/backup-components.cjs
```

仅从已验签离线包恢复缺失文件：

```powershell
node scripts/components/backup-components.cjs --repair-missing
```

已有文件哈希不匹配时保留原文件并报错，应使用应用内“离线导入（三件套）”完成重装。
