## SuYan v0.3.8

SuYan v0.3.8 is a maintenance release focused on reliable prompt editing and predictable keyboard interaction.

### Highlights

- Manual tags entered in the prompt detail view are preserved instead of being removed by the stricter AI tag filter.
- Adding, removing, or renaming a manual tag now uses the same normalized save path and keeps duplicate, empty, and over-limit values under control.
- Prompt editing and prompt creation no longer wrap the rich-text editor and its toolbar in a label element, so arrow keys stay in the editor instead of jumping to the first toolbar button.
- Added regression coverage for manual tag persistence and rich-text editor focus structure.

### Downloads

Download the four Windows packages from this release: portable or installer, with either the standard runtime or complete local optional components. Use `SHA256SUMS.txt` to verify each file after download.

The standard-runtime packages can install optional FFmpeg and NSFW components later. The complete-component packages include the verified local components for offline media processing and content rating. No package contains personal materials, account tokens, API keys, settings, or logs.

### Upgrade notes

Before replacing a portable directory or running an installer, exit SuYan and copy the complete `data` folder outside the application directory. The frozen `v0.3.7` release remains available; this release adds the fixes above without modifying its tag or assets.

## 素言 v0.3.8

这是一次提示词编辑维护版本，重点修复手动标签保存和编辑器键盘操作问题。

### 主要更新

- 修复详情页手动输入标签后按回车，标签被 AI 严格标签过滤逻辑误删的问题。
- 新增、删除和重命名手动标签统一使用独立的规范化保存路径，同时处理空值、重复值和数量上限。
- 修复新建和编辑灵感时，富文本编辑器被标签元素包裹导致方向键焦点跳到工具栏首个按钮的问题。
- 增加手动标签持久化和富文本编辑器焦点结构回归测试。

### 下载说明

本版本提供四种 Windows 发布包：便携版或安装版，以及标准运行环境或完整本地可选组件版本。下载后请使用 `SHA256SUMS.txt` 校验文件完整性。

标准运行环境版本可在软件中按需安装 FFmpeg 和 NSFW 组件；完整组件版本已包含经过验证的本地组件，可用于离线媒体处理和内容分级。发行包不包含个人素材、账号令牌、API 密钥、设置或日志。

### 升级提醒

替换便携版目录或运行安装程序前，请先退出素言，并将软件目录下完整的 `data` 文件夹复制到软件目录之外。已冻结的 `v0.3.7` 标签和附件保持不变，本版本通过新的 `v0.3.8` 提供本次修复。
