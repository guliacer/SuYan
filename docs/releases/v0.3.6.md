## SuYan v0.3.6

This release delivers a comprehensive upgrade to real account authorization, AI creation workflows, material organization, and the desktop experience.

### Highlights

- Added real Guli Identity OIDC + PKCE browser authorization, with email registration, Google, GitHub, Linux.do, device-code sign-in, and multiple linked login methods.
- Added post-login confirmation for display name and avatar, work ownership, account-verified exports, account separation, and local data protection.
- Added creative canvas background settings, theme color synchronization, generation effects, model discovery, reference-image handling, and clipboard improvements.
- Improved AI analysis, prompt cards, category and tag organization, batch management, task calendar, ComfyUI receiving, and the web assistant.
- Added Chinese / English UI switching, page-by-page guidance, import and export progress, folder memory, thumbnail fallback, and clearer error messages.
- NSFW recognition and FFmpeg are optional local components with signature verification, hash validation, and offline runtime checks.

### Downloads

- `Portable - Lite`: Extract and run; local components can be installed when needed.
- `Installer - Lite`: Install through the setup wizard.
- `Portable - Full`: Includes the FFmpeg and NSFW components for offline use.
- `Installer - Full`: Provides the complete local component capabilities after installation.

All four packages exclude user materials, accounts, API keys, personal settings, and logs. Use `SHA256SUMS.txt` after downloading to verify file integrity.

### Upgrade notes

Before upgrading or uninstalling the installer edition, exit SuYan and copy the `data` folder outside the application directory. Sign-in and online AI services still require network access; local works are never uploaded or synchronized automatically after sign-in.

## 素言 v0.3.6

本版本聚焦真实账户授权、AI 创作流程、素材组织和桌面使用体验的完整升级。

### 主要更新

- 接入 Guli Identity 真实 OIDC + PKCE 浏览器授权，支持邮箱注册、Google、GitHub、Linux.do 和设备验证码登录，可关联多个登录方式。
- 支持登录后确认昵称与头像、作品作者归属、账户验证导出，以及账户区分与本地数据保护。
- 新增创意画布背景设置、主题色联动、生成动效、模型识别、参考图和剪贴板操作优化。
- 完善 AI 分析、提示词卡片、分类与标签归纳、批量管理、任务日历、ComfyUI 接收和网页助手。
- 增加中英文界面切换、页面功能引导、导入导出进度、文件夹记忆、缩略图回退和更清晰的错误提示。
- NSFW 识别与 FFmpeg 作为可选本地组件，支持签名、哈希校验和离线运行时检查。

### 下载说明

- `便携版-无依赖`：解压后直接运行，首次使用可按需安装本地组件。
- `安装版-无依赖`：通过安装向导安装使用。
- `便携版-完整依赖`：已包含可离线运行的 FFmpeg 与 NSFW 本地组件。
- `安装版-完整依赖`：安装后即可使用完整本地组件能力。

四个包均不包含用户素材、账号、API 密钥、个人设置或日志。下载后可使用 `SHA256SUMS.txt` 校验文件完整性。

### 升级提醒

安装版升级或卸载前，请退出软件并将软件目录下的 `data` 文件夹复制到软件目录之外。登录和 AI 在线服务仍需要网络；本地作品不会因登录自动上传或同步。
