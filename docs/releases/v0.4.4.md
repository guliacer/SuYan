## SuYan v0.4.4

This release focuses on directory browsing, asset details, and image viewing.

### Highlights

- **Directory browsing**: Added a dedicated directory workspace with a directory tree, batch grouping, filtering, sorting, zooming, and descendant-folder control.
- **Image viewing**: Added immersive mode with a frosted-glass background, hides the title bar only while immersive, and allows the prompt panel width to be dragged.
- **Asset details**: Moved Export into the action row, adjusted Favorite and Select positions, and let asset count and size controls settle automatically based on panel state.
- **Bottom controls**: Changed the status bar into a floating pill at the lower-right, keeping zoom and count information without taking a full row.

### Improvements

- Moved "Include subfolders" into the More menu to reduce persistent toolbar clutter.
- Updated the README directory-browsing section with real screenshots and prompt-panel resizing guidance.

### Downloads

The Windows release packages are available as portable and installer editions, with either the standard runtime or the complete local optional components. Use the included `SHA256SUMS.txt` to verify downloaded packages. Release packages do not include personal materials, account tokens, API keys, settings, or logs.

### Upgrade notes

Before replacing a portable directory or running an installer, exit SuYan and copy the complete `data` folder outside the application directory. This release does not contain personal materials, account tokens, API keys, settings, or logs.

## 素言 v0.4.4

本版本集中完善目录浏览、素材详情和图像查看体验。

### 主要更新

- **目录浏览**：新增独立目录工作区，支持目录树、批量归类、筛选排序、缩放和子目录控制。
- **图像查看**：新增沉浸模式和毛玻璃背景，标题栏只在沉浸时隐藏，提示词面板宽度可拖动调节。
- **详情面板**：导出按钮并入操作行，收藏与选择按钮位置调整，素材数量和尺寸控制按面板状态自动归位。
- **底部控件**：状态栏改为右下角悬浮条，保留缩放和数量信息，不再占用整行工作区。

### 功能优化

- 「包含子目录」移入更多操作菜单，减少常驻占位。
- 更新 README 目录浏览章节，补充实际操作截图和提示词面板调宽说明。

### 下载说明

Windows 发布包提供便携版和安装版，并分为标准运行环境与完整本地组件两种选择。下载后可使用随附的 `SHA256SUMS.txt` 校验文件完整性。发行包不包含个人素材、账号令牌、API 密钥、设置或日志。

### 升级提醒

替换便携版目录或运行安装程序前，请先退出素言，并将软件目录下完整的 `data` 文件夹复制到软件目录之外。本版本不包含个人素材、账号令牌、API 密钥、设置或日志。
