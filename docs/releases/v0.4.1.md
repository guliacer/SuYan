## SuYan v0.4.1

This release improves image creation, task planning, sign-in reliability, and the web assistant catalog.

### Highlights

- **Image upscaling workspace**: Added a dedicated workflow for Real-CUGAN and Real-ESRGAN, with queued jobs, result comparison, runtime management, and export controls.
- **Inspiration and task planning**: Reorganized creative tools under Inspiration and refreshed the task-planning experience with a focused Today view.
- **Optional local weather**: Added first-use location and weather setup for the task-planning page, backed by free weather services. Dismissing setup keeps the page free of repeated prompts.
- **Retired-site cleanup**: Removed the discontinued Wisart site from the web assistant, recommendations, and bundled screenshots; old saved selections fall back to the default assistant site.

### Improvements

- Added a direct reprocess action for paused tasks.
- Improved location-name display for long addresses and city names.
- Improved account sign-in handling and feedback.
- Refined dialog layouts, module management, creative-canvas controls, and localized UI text.

### Fixes

- Fixed garbled Chinese text on the delete page.
- Added regression coverage for removed-site references, task-planning behavior, image-upscaling workflows, and related UI states.

### Downloads

When published, the Windows release packages will be available as portable and installer editions, with standard-runtime and complete-component options. Use the included `SHA256SUMS.txt` to verify downloaded packages. Release packages do not include personal materials, account tokens, API keys, settings, or logs.

### Upgrade notes

Before replacing a portable directory or running an installer, exit SuYan and copy the complete `data` folder outside the application directory. This release does not contain personal materials, account tokens, API keys, settings, or logs.

## 素言 v0.4.1

本版本集中优化图像创作、待办规划、账号登录和网页助手目录。

### 主要更新

- **图片超分工作区**：新增基于 Real-CUGAN 与 Real-ESRGAN 的图片超分流程，支持任务队列、结果对比、运行组件管理和导出设置。
- **灵感与待办规划**：将创作工具归入“灵感”区域，并重新整理待办事项体验，增加聚焦当天安排的视图。
- **可选天气信息**：待办页首次使用时可设置地区并查看天气，使用免费天气服务；跳过设置后不再重复弹出提示。
- **移除已下线站点**：从网页助手、推荐目录和内置截图中移除已停止服务的智画创；旧版本保存的站点选择会回退到默认网页助手。

### 功能优化

- 为暂停的待办任务增加直接“重新处理”操作。
- 优化较长地区名和城市名的显示，避免地址被截断。
- 改进账号登录流程及错误反馈。
- 优化弹窗布局、模块管理、创作画布控件和本地化界面文案。

### 本次修复

- 修复删除页面中文文字显示乱码的问题。
- 增加已下线站点引用、待办操作、图片超分流程及相关界面状态的回归测试。

### 下载说明

正式发布后将提供 Windows 便携版和安装版，并提供标准运行环境与完整组件两种选择。下载后可使用随附的 `SHA256SUMS.txt` 校验文件完整性。发行包不包含个人素材、账号令牌、API 密钥、设置或日志。

### 升级提醒

替换便携版目录或运行安装程序前，请先退出素言，并将软件目录下完整的 `data` 文件夹复制到软件目录之外。本版本不包含个人素材、账号令牌、API 密钥、设置或日志。
