## SuYan v0.4.0

This release adds local Ollama analysis, a generated-artwork gallery, and a more cohesive creative-canvas experience. The `0.4.0` version is fixed during the push preparation period and is not auto-incremented before the push succeeds.

### Highlights

- **Ollama local-model AI analysis**: Added Ollama support for local image and prompt analysis without an API key. Model capabilities and connection status are visible in Model Settings.
- **Particle effect for image viewing**: Added a restrained particle visual treatment to artwork viewing for more spatial depth without turning the page into a loading screen.
- **Generated-artwork gallery**: Added a right-side gallery to the creative canvas. It keeps every image from every prompt batch, places the newest result first, keeps older results below, and supports internal scrolling, hiding, and width adjustment.
- **Release onboarding**: New installations and upgrades show a one-time guide for the main changes and the data-backup reminder.

### Improvements

- Refined dialog feedback so messages are more natural and lightly humorous while remaining clear.
- Improved automatic negative-prompt extraction for more reliable handling of complex prompts.
- Improved document-import recognition so text split across lines is parsed accurately.
- Refined the creative-canvas background, creation core, and reveal animation, with the canvas and gallery sharing the same misty theme.
- Refined System Settings layout by reducing unused space and keeping theme, language, proxy, and related controls aligned.

### Downloads

Download the Windows packages attached to this release: portable or installer, with either the standard runtime or complete local optional components. Use the included `SHA256SUMS.txt` to verify each file. Standard-runtime packages can install optional components later; complete-component packages include the verified local components for offline media processing and content rating.

### Upgrade notes

Before replacing a portable directory or running an installer, exit SuYan and copy the complete `data` folder outside the application directory. Installation and uninstall flows may remove application-directory data. This release does not contain personal materials, account tokens, API keys, settings, or logs; a share ZIP is not a complete backup.

## 素言 v0.4.0

本版本增加 Ollama 本地模型分析、已生成作品展示区和更统一的创作画布体验。`0.4.0` 在推送准备期间固定使用，推送成功前不会自动递增版本号。

### 主要更新

- **Ollama 本地模型 AI 分析**：增加 Ollama 适配，可在无需 API Key 的情况下使用本地模型完成图像和提示词分析，并在模型设置中展示模型能力与连接状态。
- **图像查看粒子效果**：为页面查看图像增加克制的粒子视觉效果，增强作品浏览的空间感，同时避免变成 loading 页面。
- **已生成图像展示区**：在创作画布右侧增加作品展示区，完整保留不同提示词批次的所有结果，最新结果置顶、旧结果向下排列，并支持区域内上下滚动、隐藏和宽度调整。
- **版本引导**：新安装和版本升级后显示一次引导，帮助用户了解主要变化，并提醒升级前备份完整 `data` 文件夹。

### 功能优化

- 优化部分弹窗反馈文案，让提示更自然、轻松，同时保持信息清晰。
- 优化负向提示词自动提取，提升复杂提示词的识别稳定性。
- 优化文档导入识别规则，换行文本也能准确识别。
- 优化创作画布背景、AI 创作核心与显影过程动效，让创作区和作品展示区保持统一的柔雾主题。
- 优化系统设置布局，减少无效留白，并让主题、语言、代理等设置保持一致的空间结构。

### 下载说明

请从本版本 GitHub Release 附件中选择对应的 Windows 安装版或便携版，并使用随附的 `SHA256SUMS.txt` 校验文件完整性。标准运行环境版本可在软件中按需安装可选组件；完整组件版本适合离线媒体处理和内容分级。

### 升级提醒

替换便携版目录或运行安装程序前，请先退出素言，并将软件目录下完整的 `data` 文件夹复制到软件目录之外。安装和卸载流程可能移除软件目录中的数据。本版本不包含个人素材、账号令牌、API 密钥、设置或日志；分享 ZIP 不能代替完整备份。
