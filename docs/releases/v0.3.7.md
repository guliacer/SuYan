## SuYan v0.3.7

SuYan v0.3.7 is the current stable release after the frozen v0.3.6 release. It focuses on dependable large-library backups, broader AI gateway compatibility, and safer delivery.

### Highlights

- Large libraries are automatically split into capacity-based backup volumes. Multiple volumes can be selected and imported together, while shared category, tag, and cover resources are deduplicated.
- Background export now reports its phases and keeps the main interface usable. Import and export dialogs remember the last folder used.
- OpenAI-compatible AI endpoints accept non-streaming, SSE, NDJSON, UTF-8 BOM, and common response envelopes. This improves reverse prompting and structured AI analysis across gateways.
- Sanitized diagnostics record the endpoint, model, response format, and stage without recording API keys, full prompts, or image data.
- Added ComfyUI quick-save and TapRelay completion-notification instructions, with matching README screenshots.
- Added four Windows packages: portable / installer editions with the standard runtime or complete local optional components. Every package has SHA-256 verification metadata.

### Downloads

Download the package that matches your workflow from the assets below. The standard-runtime editions are suitable when optional local media processing or content rating can be installed later. The complete-component editions include the verified local FFmpeg and NSFW runtime for offline use.

Before running an installer or replacing a portable directory, close SuYan and back up the entire `data` folder somewhere outside the application directory. The installer and uninstall process may remove the application directory data; a share ZIP is not a complete backup.

### Upgrade notes

The release does not contain personal materials, account tokens, API keys, settings, or logs. Online AI generation and account sign-in still require network access and user configuration. After upgrading, restore the backed-up `data` folder if needed.

## 素言 v0.3.7

这是继已锁定的 v0.3.6 之后的当前正式版，重点提升大素材库备份、AI 网关兼容性和发布交付可靠性。

### 主要更新

- 大型素材库会按容量自动分卷备份，支持多卷一起导入，并对共享的分类、标签和封面资源去重。
- 导出任务增加阶段进度并在后台执行，导入 / 导出目录会记住上次使用的位置。
- OpenAI 兼容 AI 接口支持非流式、SSE、NDJSON、UTF-8 BOM 和常见响应包装，提升图像反推与结构化分析的兼容性。
- 增加脱敏 AI 诊断信息，记录服务端点、模型、响应格式和处理阶段，但不会记录 API 密钥、完整提示词或图像内容。
- 增加 ComfyUI 快捷保存与 TapRelay 生图完成通知的使用说明和配套截图。
- 提供便携 / 安装两类、标准运行环境 / 完整本地可选组件两种组合，共四种 Windows 发布包，并附 SHA-256 校验信息。

### 下载说明

请根据使用方式从下方附件中选择对应的便携版或安装版；需要离线使用本地媒体处理和内容分级时，选择完整本地组件版本。所有附件均可使用 `SHA256SUMS.txt` 校验。

### 升级提醒

运行安装包或替换便携版目录前，请先退出素言，并将软件目录下完整的 `data` 文件夹复制到软件目录之外。安装 / 卸载过程可能移除软件目录中的数据；分享 ZIP 只适合交换选中作品，不能代替完整备份。发行包不包含个人素材、账号令牌、API 密钥、设置或日志。
