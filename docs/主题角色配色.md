# 主题角色配色

主色调负责导航选中、页面重点和主题区域；次要色负责按钮、快捷操作和表单交互；第三色负责休息日与辅助信息。工作日保留中性背景，休息日使用第三色的浅底、描边和专用文字色，选中日期仍使用主色轮廓，文字标签继续区分工作、休息和手动调整。

主题面板原来的“按钮颜色”更名为“主色调”。新增次要色、第三色色选器与角色预览，支持恢复自动配色。自动配色按主题预设及浅色/深色模式切换；用户自定义角色色在各主题间共用，存入原有 view-settings.json 的 customTheme.secondaryColor/tertiaryColor，旧文件缺字段时使用自动配色。原有三个自定义主色槽不迁移、不重解释。

颜色定义集中在 src/styles/tokens.css。secondary 和 tertiary 均提供柔和底色、文字色及描边；按钮使用 secondary-foreground，自动在深字与浅字中选择更高对比度。自定义工作区和导航背景的文字对比度分别计算。危险、警告色保持独立语义。

共享 Button、弹窗标题、月历和主题面板已接入。为使素材、分类、标签、资源、账号、AI 设置、画布与灵感等既有页面的原生操作按钮同步协调，CSS 兼容层将操作按钮内部的旧 primary 令牌映射为 secondary；导航、tab、主题样本、明确 data-color-role 和日期单元格除外。新增组件优先显式使用 secondary 令牌；独立语义控件可通过 data-color-role 声明角色。资源内容本身的分类胶囊不改为统一颜色。

验证：themeMode.test.ts 覆盖旧设置兼容、角色色独立保存/恢复、跨主题切换、自定义深浅背景；check-theme-roles-ui.mjs 检查 10 个主题的明暗模式、1100/390px、共享和旧按钮的配色一致性、休息日文字对比度与自定义恢复。check-todo-calendar-ui.mjs 继续覆盖月历操作。
