# 素材目录模式设计说明

## 目标与最新范围

将素材目录升级为 Billfish 风格的本地目录工作区，保留 Electron 标题栏，隐藏普通导航。按真实目录层级展示素材，不再把全部素材默认摊开。2026-11-14 用户最后的布局修正覆盖此前“统一浏览设置”和“四种分类导航”的方案。

## 目录组织

- 左侧仅显示“全部目录”和真实/逻辑目录树；目录模式及其大图查看器均不展示“未归类”入口或不属于目录的素材。
- 概览默认展示文件夹卡片；选择目录显示该目录的直接素材。“包含子目录”开启后才聚合后代。
- 外部索引按 rootId / relativePath 归类，复制导入按来源目录归类，手动目录关系覆盖默认关系。
- 支持多级逻辑目录、重命名、目录拖拽排序/嵌套、素材单个/批量拖入；防止自身和子孙循环。
- 逻辑整理和颜色设置只修改本地元数据，不移动、重命名或改写外部原图。
- 目录及大图树使用统一柔和文件夹配色，子目录默认继承，右键可覆盖颜色或恢复自动/继承。

## 默认页面与浏览操作

- 顶部保留路径面包屑、搜索、瀑布流/网格/列表图标、排序图标、筛选图标、信息面板图标、唯一的添加目录入口和更多菜单。
- 不再渲染“浏览设置”综合面板，也不在左侧菜单底部重复添加素材目录。
- 排序图标打开紧凑菜单：名称、导入时间、更新时间、文件修改时间、大小、格式、评分、稳定随机，共八种，支持升降序。
- 筛选图标单独打开类型、格式、标签、分类、评分、可用状态和收藏筛选；标签/分类是目录素材内的筛选条件，不切换成独立导航工作区。
- 选择操作区默认只保留全选与右侧“包含子目录”，有选中素材才显示批量动作。
- 缩略图尺寸放在结果列底部，160–360px 滑杆和缩小/放大图标；双击滑杆恢复 220px。
- 素材数量置于结果列底部最右侧，不重复放在顶部或左侧页脚。
- “退出目录模式”固定在左侧最底部；结果列页脚不得横跨左栏，也不得在退出按钮下方再占一行。

## 素材详情与点击

- 单击只选择素材并显示轻量素材信息；双击才打开大图详情卡。
- 卡片格式标识位于左侧，选择框位于右侧，避免重叠。
- 大图详情卡保留左侧目录树、中央适应窗口的大图、底部当前目录缩略图。
- 右侧默认窄信息轨，以大图为主；明确点击“展开提示词”才惰性加载原有完整提示词编辑器，收起后卸载。
- 连续切图保留同一查看器会话；使用有界缩略图窗口/预取，不因单击更换素材反复重挂载整个查看器。
- 方向键/PageUp/PageDown切图；文本输入、选择框和编辑区中的这些按键只作用于编辑，不触发切图。Tab焦点限制在查看器，退出恢复浏览区焦点。
- 定位目录切换底层工作区、展开祖先、清除不相关过滤器并关闭查看器，不能只落盘而保持旧目录。
- 主色采用有界像素采样及缓存；色块/代码一击复制 HEX、RGB 或 CSS，显示成功/失败反馈，不阻塞看图。

## 数据与媒体兼容

- 继续使用本地 library.json + images/ 及既有外部索引、preload白名单和媒体协议。
- libraryDirectorySettings 保存逻辑节点、归类、颜色、布局、尺寸、排序和筛选；旧“未归类”或标签/分类/格式导航设置进入目录模式时修复为概览，原素材和偏好不删除。
- 视图设置通过串行队列与 Windows 可重试原子 JSON 写入保存；唯一临时文件、滚动备份，失败回滚并在页脚显示错误。
- 缩略图覆盖缺失、过期、生成中和失败回退原图；支持外部 PSD 合并预览。
- 图片复制按内容解码，扩展名不符也可复制；同提示词组原图第一、后续效果图追加。
- 正式数据保持 release/win-unpacked/data，日志保持程序目录 logs；QA 使用隔离夹具，不迁入正式库。

## 验收

1. 目录组织、目录专属范围、单击/双击、选择框位置、独立图标及页脚位置均有回归测试。
2. 连续目录/查看方式/排序/尺寸切换、颜色继承及刷新保留、复制成功/失败、焦点边界、跨目录定位、PSD和响应式显示通过真实 UI 检查。
3. 使用指定的 2026-09 目录执行真实导入/二次扫描，校验135个素材、16个子目录、缩略图及源文件完整性，保留原图库。
4. 全量单元测试、两个进程的类型检查、构建、diff检查以及 pnpm package:win 必须完成，并启动正式产物验收。开发快速包不生成安装包/ZIP，不推送或发布。
