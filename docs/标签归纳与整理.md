# 标签归纳与整理

标签浏览顶部「AI标签」旁的「归纳整理」用于检查现有标签的标准名称、分组及影响的作品组数量。进入页面只生成预览；点击「应用勾选项」并再次确认才写入标签库与作品标签。

- 建议整理：一起提供未归类标签、同义词统一和已有分组的纠正建议，不新增独立纠错入口。左侧保留原名称与原分组，右侧展示建议；已确认的标准分组若与完整词义冲突，也会列出，但默认不勾选。检查后使用原有「选择当前建议→应用勾选项→确认执行」，支持最近一次撤销。
- 原未归类：集中检查“其他标签”、旧“空间环境”等未细分分组，展示可归类数量与仍需复核数量。批量选择只勾选当前筛选范围内有可靠调整建议的标签；用户自定义分组及其子层级不参与自动纠错建议。
- 待归纳：缺乏依据、模型置信度偏低或无法确定分组的标签，需要人工确认。分组可自由输入，使用 `/` 分层。
- 疑似噪音：平台名称、疑似编号或画面文案，默认不勾选、不自动删除。
- 全部标签：包含已确认项，可继续调整名称与分组。

明确的同义词可统一，例如“胡杨树→胡杨”“手托脸颊→托腮”。红叶、黄叶、绿叶以及假山、假山石分别保留。被替换的旧名称保存为别名，标签浏览搜索仍可使用旧名称。作品数量按现有提示词组规则去重，不把一个组的多张效果图重复计算。

后续分析复用用户确认的名称、别名、封面和自定义分组；标准分组每次按完整词义重新核验，即使旧标准分组已被标记为已确认，也不能盖过明确规则。新分析只更新本次识别涉及的词条，不在启动时批量改写旧库。新的 AI 标签结果保留维度、依据、模型置信度与最终建议分组；模型置信度仅供参考，不代表实测准确率。较低置信度、缺乏依据或包含“疑似/可能”等不确定依据的保留项进入待归纳，打开归纳整理也不会自动解除待复核状态。没有依据的低质量候选会被过滤，不用现有词库反推图片里必然存在某种内容。

本地文本分析、远程提示词分析和效果图分析共用 `buildAnalyzedTagEntry` 的最终分组校验，不再使用旧的局部字词分类作为新标签的兜底。具体实体即使同时被参数解析识别，也能作为标签保留；本地原文匹配依据单独标明。多义词须有对应的自身依据：纸页/手写内容对应纸本，键盘/屏幕对应电脑；证据不足或冲突时保持待归纳。两条分析路径都须先成功保存分组和依据，再返回可应用标签；写入失败或连接中断时恢复未保存的词库状态，并明确提示本地保存失败，不误报成 API 鉴权问题。回归见 `tagAnalysisGrouping.test.ts`。

品牌与文字质量补充：SONY/索尼等相机品牌、α7C 等相机型号分别归入「物品/数码设备/相机品牌」「物品/数码设备/相机型号」。新识别要求该候选自身有对应设备依据，不能靠同批其他标签、文件名或水印推断。HUAWEI 是设备品牌、XMAGE 是影像技术，只有边角标识时不添加为图像标签。旧库复核可利用关联作品的明确器材标签提出分组建议，不会自动应用；白线同时出现车道线/公路时建议道路设施，无法确认用途的线条保留视觉特征分组。

「大、道」、随机编号、平台/作者水印、误读标识以及泛泛评价不进入新分析结果；马、树、雾等有效单字实体仍保留。已确认的词条不会被自动删掉，但不能作为每张新图必须生成该词的理由。旧库疑似噪音项仍由用户确认是否保留，可在标签浏览删除单个无用标签。新模型返回 0–15 个标签，不设最低数量；只有明确以文字为主体的设计内容才允许文案标签。合法的空标签响应视为完成，不触发解析重试或本地凑词。

「撤销上次整理」仅恢复最近一次整理涉及的标签和词库，不回退后续修改的标题等资料，也不删除后来导入的作品。如果相关作品标签或词库已有新改动，撤销会停止，避免覆盖用户的新内容。恢复记录保存在本地库目录的 `tag-organization-undo.json`，下一次成功整理会替换这份记录。

词库 JSON 导入和导出会保留别名、确认状态、分组及识别依据。旧格式仍可读取；旧数据不会因为打开标签页就自动批量改名或改组。

2026-09-10 扩充实体词汇与受约束的修饰词组合，旧库预览、新导入标签和后续 AI 识别共用规则。例如白桦树干进入树木、芭蕉叶进入叶片、矮几进入家具、闭目和手持花枝进入动作；玫瑰窗属于建筑，玫瑰花纹属于纹样，不能因包含“玫瑰”全部归入花卉。颜色、材质及高矮等特征保留原名，仅调整分组。规则无法确认含义的词仍待归纳；新增分组规则不能解除低置信度或缺乏画面依据的待审核状态。

复合词规则补充：蝴蝶发夹/蝴蝶结发带进入配饰，蝴蝶结肩带/牛角扣进入服装结构；手持蝴蝶/手持相机/手持玻璃杯进入动作。玻璃杯是物品、玻璃是材质、玻璃态是界面效果；兔子摆件是道具、兔子是动物、羽毛/翅膀进入动物身体特征。手提包、手提篮、捧花是已经成词的物品名称，不能拆成动作；陌生复合词不沿用旧包含匹配的分组兜底。笔记本、镜头、布偶等多义词在旧库预览中进入待复核，不强行判定。编号前带「动漫」也不能变成有效风格标签。

2026-09-10 本轮只读复核覆盖 1017 个标签、42 个现有分组，产生 150 个已有分组纠正建议，并保留 5 个待归纳、14 个疑似噪音供复核。默认勾选不会修改已确认词条；内存模拟用户主动选中全部建议后，1361 条素材及其标题、标签、图像和其它元数据完全不变，自定义分组与未勾选词条保持不变。以上是当前词库的规则审查结果，不是模型准确率；程序启动不会批量改写数据。使用 `node scripts/check-tag-coverage.mjs --details` 可重新只读核查各分组和每项原/建议分组。
