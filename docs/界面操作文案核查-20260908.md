# 界面操作文案核查（2026-09-08）

范围：当前素言桌面项目的中文操作文案与状态来源，包括 src 中账户、素材浏览/详情、画布、分类/标签/参数词库、AI 设置、NSFW/组件管理、系统/代理/启动设置、灵感/待办、批量压缩去重，以及通用确认框、通知、日志导出和更新提示；结合 store 与 IPC 返回结果核对成功、失败、取消和等待的含义。非产品资源（提示词内容、用户素材、历史文档）未做措辞改写，未更改独立 Identity 服务。

## 已修正

| 位置 | 原因 | 当前行为 |
| --- | --- | --- |
| 账户页退出按钮 | 共用 isSubmitting 被解释为退出 | submittingAction=logout 时才显示正在退出，其余操作保持退出登录并禁用 |
| 关联按钮 | 打开授权页期间无目标操作反馈 | 目标渠道显示正在打开授权页，返回后显示等待关联确认 |
| 登录/绑定确认、注册、取消 | 任一账户请求触发同一忙碌文案 | 每个按钮仅匹配自身操作，选择头像不会显示确认中 |
| 已绑定方式 | 将身份服务 guli 当作登录渠道 | 只展示实际登录方式，不把服务本身计入数量 |
| 关联等待 | 取消绑定暗示撤销已确认的服务端关联 | 停止等待；超时提示刷新资料查看结果，说明不撤销已确认关联 |
| 登录回调说明 | 保证自动返回，忽略浏览器协议拦截 | 提示手动点击浏览器返回素言入口并完成资料确认 |
| AI 设置备份 | 全局忙碌被解释为读取/导出/导入，真实 IPC 请求未持有独立状态 | 独立 pick/apply/export 状态与失败提示；首次读取错误也可见 |
| 画布/详情参考图 | 两个互斥入口同时显示导入中 | 保留入口名，统一区域提示正在添加参考图 |
| 组件管理 | 开关/恢复动作导致删除按钮显示删除中 | 按 actionKind 区分删除、恢复与启停 |
| 分类/标签清空 | 失败状态写成 canceled | 独立 failed，显示操作失败 |
| 词库保存与批量分析 | dirty 被解释为正在同步；有失败项仍笼统已完成 | 有待保存的修改/当前已保存；批处理失败项明确提示 |

## 验证边界

账户 store 增加延迟请求测试，覆盖关联、刷新、昵称、头像、解绑、退出、注册、确认、取消的操作归属及失败清理。真实 Edge 使用当前 React 组件与延迟 IPC 测试替身，覆盖 974/390px：关联开始/等待/停止、退出、取消确认、导入导出，并检查未触发的按钮不出现进行中文案。该测试不操作个人账号，不创建真实关联。

其他页面通过源码状态分支与现有回归测试核查；没有声称穷举每种平台、网络或用户数据组合。后续新增操作必须分别定义 busy 禁用与操作语义，禁止用共享 isBusy/isSubmitting 决定具体动作名称。

命令：pnpm typecheck；pnpm test；node scripts/check-action-copy-ui.mjs <已安装 Playwright 路径>；pnpm package:win。项目没有 lint 脚本。
