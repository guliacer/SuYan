# 分享包中的分类与标签库

默认 ZIP 文件名为 `素言-v软件版本-提示词-YYYY-MM-DD-HH-mm-ss.zip`，例如 `素言-v0.3.6-提示词-2026-09-10-12-30-45.zip`。版本读取当前运行的软件版本，日期和时间取导出时的本地时间（精确到秒）；单组与批量导出使用相同命名规则，用户可在保存窗口自行修改名称。

其他导出入口也采用 `素言-v软件版本-内容类型-日期-时间.扩展名`：图像/视频/音频作品、分类词库、标签词库、灵感库、AI 设置与应用日志。AI 设置名称区分普通、密码加密、账户加密三种方式，原有加密格式保持兼容。新版灵感库交换文件记录导出方时区，跨时区导入可校验；旧版文件仍可导入。

导出任务在右下角显示可收起的进度面板，不遮罩或锁定页面，切换页面不影响任务。分享包显示素材检查数量、压缩进度和文件校验状态；无准确百分比的步骤显示当前阶段，不模拟进度。ZIP 压缩在独立线程或 Rust 子进程中运行，通过临时文件校验后再替换目标文件；失败保留原文件。同一窗口同时运行一个导出任务，不影响其他页面操作。

系统文件选择框分别记住上一次确认的导入目录与导出目录，保存在 `data/library/file-dialog-settings.json`，重启后继续使用。选择目录时记住目录本身，选择文件时记住所在目录；取消选择不更新记录。目录失效时使用原有默认位置；导出仍使用当前版本与时间生成的新文件名。目录记录不随分享包或发行包导出。

批量管理的「导出所选」会自动携带所选提示词组及其效果图、主分类和附加分类、相关分类与标签词条、父级分组、别名、说明、分析依据及封面图。只打包所选作品用到的词条和父级，不复制无关词库或个人设置。分类/标签封面即使来自未选中的外部素材，也会读取原图一同打包，不泄露外部路径。

导入时恢复分类和标签的原有分组，不重新调用 AI 或根据提示词猜测。已有同名词条保留本地分组、说明和已有封面；缺失的封面、别名、分析记录可以补全。相同分类 ID 指向不同内容时，给导入分类分配新 ID，并只调整本次导入作品的关联。本地已有作品不因导入被改写。

分类库、标签库和作品在同一写入队列中合并；写入失败会恢复原词库并清理本次写入的图片。如果磁盘问题导致恢复也失败，会明确报错并保留备份和图片。导入结果直接刷新界面，排队中的旧设置保存不能覆盖刚导入的资料。

格式仍为 schemaVersion 2 的 `data.json`，新增可选 `analyzedLibraries`（schemaVersion 1，包含 `categoryTaxonomy`、`categories`、`tags`）。封面使用 `knowledge-images/`，与所选效果图相同的封面复用 `images/`。导入后文件名重新分配并同步替换词条引用，原始创建时间保留，确保原始效果图在前、追加图在后。

旧版 v1/v2 分享包仍可导入，但之前没有打包的分析记录无法从旧包恢复；需要重新导出。接收方也需要使用支持该字段的版本才能恢复词库。

分享包用于分享所选作品，不是完整备份。升级备份仍应复制整个 `data/` 目录；分享包不包含完整设置、API 密钥、全部词库、外部库挂载、启动图库等用户数据。

验证覆盖：`archiveKnowledge.test.ts`、`archiveKnowledgeIntegration.test.ts`、`archiveKnowledgeRenderer.test.ts`、`archiveExportRustIntegration.test.ts`。包含真实 ZIP 与 JSON 落盘、外部封面、分类 ID 冲突、写入回滚、旧包兼容、扩展名与真实图像格式不一致、原图顺序和设置保存竞态。
