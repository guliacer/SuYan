# 待办月历与工作日

规划页按自然月显示，以周一为每周第一天，可切换月份或回到本月。点击日期查看当天事项，可拖入任务或使用“安排到所选日期”。没有计划日期的未完成事项才列入待规划；其他月份的事项保留原计划。

支持双休（周六、周日）、单休（任选每周休息日）、大小周。大小周以用户指定日期所在周为双休基准周，下一周仅休周日，连续跨月、跨年轮换。切换模式不改变已有任务的计划日期。

日期优先级为个人调整、法定放假/调休、工作模式。点击日期后在“当天安排”中选择自定义工作日、休息日，或自动恢复默认。调整与模式保存到 data/library/todo-calendar.json，采用原子写入和滚动备份，独立于任务撤销记录。

联网使用 https://raw.githubusercontent.com/NateScarlet/holiday-cn/master/{year}.json。holiday-cn 是依据国务院通知整理的开源数据，不是政府官方 API。主进程通过 Electron net.fetch 查询，固定地址、12 秒超时、256 KiB 上限并校验日期、年份和布尔字段；不发送任务、账户或其他个人资料。默认应用中国大陆放假和补班，用户可关闭。

年度缓存位于 data/library/holiday-cache/{year}.json，24 小时内复用；可手动刷新。更新失败保留有效缓存，无缓存或尚未发布的年份明确显示提示，按工作模式与个人调整显示，不宣称已取得官方排班。

验证入口：tests/unit/todoWorkCalendar.test.ts、todoCalendarStore.test.ts、todoPlanning.test.ts。scripts/check-todo-calendar-ui.mjs 使用真实组件与模拟 IPC 验证界面；scripts/check-todo-calendar-live.cjs 在独立临时目录用真实 Electron 网络验证 2026 年数据和持久化，不修改用户正式日历。
