# 待办导入导出

待办事项右上角「更多待办操作 → 导出事项」支持全部导出；勾选事项后，批量操作栏提供「导出所选」。导出确认框沿用软件弹窗样式，可选择全部或所选范围。

文件命名为 `素言-v版本-待办事项-YYYY-MM-DD-HH-mm-ss.json`，使用统一目录记忆、后台任务和进度面板。导出只读取任务快照，不占用编辑状态或保存队列；等待选择位置与写文件期间仍可继续使用软件。

JSON 保留任务说明、状态、优先级、进度、日期、估时与耗时、标签、归档状态、项目资料和父子关系。全部导出还包含进度视图设置；所选导出只携带对应项目及所选任务之间的父子关系。不包含工作日设置或关联提示词正文。

通过「导入事项 → 选择文档」重新打开此文件，会识别为完整待办文件，确认后追加独立副本，并重新映射任务、项目与进度视图之间的引用。现有事项不覆盖，相同标题也不合并；导入可撤销。为避免关联到其他用户的提示词，导入后需手动重新关联提示词。普通文本、表格、Word 导入继续使用原有识别预览流程。

回归验证：`todoExchange.test.ts` 覆盖真实 JSON 写入与读回、归档和父子关系、所选范围、取消导出、导出不锁定保存队列及无效批次不部分落盘；`check-todo-export-ui.mjs` 验证实际按钮、范围弹窗、后台交互和完整文件导入。
